十一、诚实边界（不夸大）

  • 浏览器按钮不生产新数据。抓取 / 预测 / 提取 / 赛果回溯必须由后台 Python 流水线完成后部署到 Pages，按钮只把云端当前已部署的最新批次同步到本机。这是物理边界，不是偷懒。
  • 数据能否持续变新，取决于后台每小时自动保鲜任务。该任务此前被停用（status=0）导致 30 小时停摆，本轮已恢复为启用并复核生效；下一个整点会自动跑 auto_pilot.py 全闭环。
  • 竞彩官方接口在海外不可达（HTTP 567），当前走 500.com 备用源，页面上如实标注「备用源」，不假称直连官方。
  • 海外 CI 的 /api/refresh 通道仍保留健康探测与 run 状态查询，但不再由前端按钮触发，也不再对外宣称会产出数据。
